# 光之小英雄

面向儿童的第一人称 3D 体感游戏。Three.js 渲染巨人视角的城市、迪迦的蒙皮手臂与面前的怪兽；MediaPipe 在本机分析动作。雷德王、巴尔坦星人、加恩Q 起头，十四波远近战（最终 boss 加坦杰厄），四种远程招式、胸前 X 护盾与侧身闪避、星星奖励与合成音效。部署于 https://adoin.github.io/ultraman-play/ 。

## 本地运行

```sh
npm ci
npm test
npm run build
npm run dev
```

打开 http://localhost:4173 。不需要摄像头也能按 J / U / K / O 或点击技能卡游玩，按 Z 出左拳、X 出右拳，F 或点击画面交替出拳，按住 L 防御、按住 A / D 侧身闪避。准备区可看动作图解、设置画质难度、开启摄像头和视频预览，确认后再进入。进入后保留城市、怪兽、动作特效与双方血条，准星、摄像头预览、文字提示和按钮均在准备区。待机不显示双手，出拳、技能和防御时才显示。Esc / P / 空格或手机双指轻点返回准备区；继续后回到仅有双方血条的战斗。通关或失败时也返回准备区显示结果。设置包含难度、画质、安心练习与识别诊断。摄像头部署必须 HTTPS；localhost 可开发。使用支持 WebGL 2、Worker、OffscreenCanvas 与 createImageBitmap 的近期 Chrome / Edge / Safari，性能不足可切换流畅画质。

`npm run build` 同步 Three.js 运行时并生成 `dist/`，`npm run dev -- --dist` 预览发布文件。无前端框架或打包器。Three.js、GLB、MediaPipe、WASM 与姿态模型均随站点部署，运行时不请求第三方模型 CDN。字体加载失败自动使用系统字体。

## 3D 模型

`art/models/*.blend` 是 Blender 可编辑源文件，`public/models/kaiju/*.glb` 是网页模型。建模与免费模型来源说明见 [art/README.md](art/README.md)。使用本机 Blender 的后台模式生成，没有修改用户已打开的 Blender 项目。怪兽动画由命名枢轴驱动。迪迦手臂来自 Extrazhang 的连续人物网格。每侧有 18 根手臂和手指动作骨骼，肩根按原模型的双眼和肩骨定位。GLB 纹理和蒙皮着色器在准备界面做离屏预热。

准备界面的“鸣谢”列出模型作者、来源、CC BY-NC 许可及适配说明，并列出 Three.js、MediaPipe、Noto Sans SC 的来源和许可；战斗中该入口与其他 HUD 一同隐藏。本游戏与迪迦模型衍生物为非商业使用。源文件、许可出处、哈希和修改记录见 [art/sources/tiga/SOURCE.md](art/sources/tiga/SOURCE.md)。

`npm run test:tiga` 验证实际 SkinnedMesh、骨骼数、权重归一化、指尖蒙皮位移、纹理、作者元数据、鸣谢及手机动作画幅。

独立[全身动作对照页](https://adoin.github.io/ultraman-play/public/motion-preview/)同步播放同一具迪迦全身骨架的外部视角与双眼视角。试片使用 Quaternius 的 `Punch_Cross` 直拳，保留胸、锁骨、肘腕、五指及腿部动作。点击暂停或拖动时间轴可检查同一帧。这份试片用于验证现成动作的重定向与眼位取景，游戏中的光线仍使用当前游戏动画。用 `?model=tiga-flight.glb&clip=Flight` 可在同一页检查庆祝用的升空姿势（静态网格，无动画轨道）。

第一人称角色以原模型双眼中点确定肩位。普通动作沿用原始骨长。光线用画面中的肘、腕目标确定横臂长度，袖子网格沿前臂轴向补偿，手掌保持原始尺寸。梅特里姆光线是为迪迦骨骼手调的动作。右肘稍向右打开，右腕处在肘的正上方。左前臂从怪兽一侧横过，左掌朝地。`src/viewmodel-lens.js` 为双臂提供较宽的取景，将光线和光轮的发射位置换算到城市镜头的相同屏幕位置。

`src/action-timing.js` 统一动作、光效和伤害时间：光线在 0.32 秒定姿、0.42 秒开始发射、0.64 秒接触目标；按键光轮在 0.45 秒举高、0.72 秒脱手、1.1 秒接触目标；摄像头已经完成举高时直接接续甩出，0.2 秒脱手、0.58 秒命中。光线发射带跟随真实前臂，光轮脱手前跟随手腕方向；命中特效跟随当前怪兽胸部核心。特殊技能占用双臂直到收势结束，期间拒绝其他出拳/技能/防御输入，不消耗被拒绝技能的冷却。

`npm run test:animation` 在 Chrome 中测量肩宽、肩位漂移、两条上臂的入画位置、十字交点处右臂的遮挡以及发射点的屏幕位置。检查覆盖桌面、手机和平板，输出第一人称、正面、侧面和动作阶段截图。发布前查看完整动作，检查肩部轮廓、手型和光效遮挡。截图默认位于 `D:/tmp/ultraman-animation-check`。

## 战斗

普通出拳：每拳 12 点伤害，单次动作间隔至少 0.28 秒，独立于技能冷却、不消耗护盾能量。Pose 根据屈肘收拳→前推伸臂→收回的连续动作判定，不依赖指尖模型；手臂保持伸直不会连发。支持左右手、F 键和点击画面。摄像头前推时的深度由单目姿态估算，需要继续实机验证不同视角与儿童动作。

十四波战斗依次是雷德王（110）、巴尔坦星人（210）、巴尔坦星人·量产型（235）、加恩Q（185）、美菲拉斯星人（200）、巴尔坦星人·强化体（250）、机械巴尔坦（270）、卡欧斯·赛文（265）、卡欧斯·泰罗（285）、卡欧斯·奥特曼（305）、杰顿（400）、机械哥莫拉（340）、迦拉克隆（440）、加坦杰厄（560，最终 boss，体型放大 1.12 倍），血量与技能组合逐波提升。怪兽攻击依次经过蓄力预警、发射和命中判定；蓄力阶段不会扣血。能量弹和冲锋可侧身躲开，横扫需要向提示的安全方向闪避，震波需要护盾；所有攻击都能用有足够能量的护盾格挡。护盾一次最多维持 2 秒，提前松手或到时收盾后冷却 4 秒。持续交叉双臂或按住 L 只触发一次。防御期间消耗能量，收盾后恢复。光线可打断怪兽蓄力。击败怪兽恢复部分生命与护盾，成功防御/闪避额外奖励星星；通关后可重新开始。

## 胜利庆祝：飞向宇宙

十四波怪兽全部击破后不再立刻结算。战斗引擎同时置位 `finished` 与 `celebrating`，等 `src/combat.js` 里的 `CELEBRATION.duration`（7.5 秒）走完才发出 `celebration-end`。这段镜头按奥特曼升空的节奏推进：

1. **0–1.4 秒**：第一人称手臂与护盾层隐藏，迪迦全身模型站上广场、面向镜头保持原始 A-pose（`public/motion-preview/tiga-flight.glb`，下载版全身模型，处理方式见 `art/sources/迪迦/SOURCE.md`），镜头从人眼位置后拉到 `(0, 10.6, 33)`，脚下光点与礼花升起；
2. **1.4 秒之后**：模型按 `climb = (age-1.4)² × 3.2` 加速升空，后仰最多 0.45 弧度并在 1 秒后缓慢转身飞离，尾迹光点跟随；因为这个模型的肩部权重只适合原姿势，举拳姿势会撕开接缝，所以升空靠身体倾斜和镜头表达；镜头抬高最多 8 个单位、视线最多抬高 30 个单位；
3. 升空同时 `skyMat` 的两段天空色向深空过渡（顶 `#040a18`、底 `#0a1a33`），900 颗星在半径 380 的球面上淡入，读到“飞出地球”；
4. **3.2 秒起** `#celebration` 横幅淡入“守护成功”，`src/game-audio.js` 播放胜利号角并触发 `victory` 台词，音乐保持到庆祝结束才停；
5. 7.5 秒后回到准备区结果面板，天空色、星空、模型与镜头全部复位。

暂停会冻结倒计时；重新开始会清理庆祝状态。庆祝台词当前是 Windows SAPI 的临时占位音频，替换步骤见 `public/audio/SOURCE.md`。

## 怪兽按需加载

第一次进入不再一次拉完五只怪兽：

- `loadAssets()` 只等待城市、第一波怪兽（`WAVES[0].model`）和第一人称手臂，加载完就发出 `assets-ready`，进场按钮此时已可用；
- 紧接着 `primeMonsters()` 按 `WAVES` 顺序在后台流式预取其余怪兽，全部完成后发出 `monsters-ready`；
- `loadMonster()` 对同一模型合并并发请求；`selectMonster()` 在模型未到时等待加载完成再重试，所以网络慢也不会出现空怪兽；
- `scripts/models-check.mjs` 会先 `await battle.prefetch` 再断言模型细节。

除雷德王与加恩Q 外的九只敌人全部来自 MMD 素材（四个巴尔坦、美菲拉斯、机械哥莫拉、卡欧斯三兄弟），转换流程见 [art/README.md](art/README.md#mmd-怪兽转换)。旧的巴尔坦 GLB 已被新模型替代。它们保留**完整骨骼**（`MUNE`/`ZYOUWAN`/`UDE`/`TE`/`MOMO` 等），由 `src/monster-motion.js` 的 mmd 分支按攻击类型驱动：充能抬爪、发射前刺、近战直拳、冲锋前倾迈步、受击后仰、倒地后折；投射物起点取自真实手骨 `_TE`，不再是从身体里凭空冒出。

## 体感规则

- 梅特里姆光线：肩、肘、腕可见；两条前臂接近，一条偏横、一条偏竖，**并且真的交叉成 "＋"**，在胸前保持 420ms（标准 600ms）。伤害 46，冷却 6.5 秒。
- 哉佩利敖光线：同样一横一竖，但两条前臂**在角落里相接而不交叉**（摆成 L 形），在胸前保持 700ms（标准 850ms）。伤害 82、冷却 9 秒，是本作最强的一击；两条前臂交叉会被判成梅特里姆光线，所以「交叉」与「L」互斥。
- 光轮：任意手腕举过头顶并保持 320ms（标准 480ms），再在 2.5 秒内向前下方甩出。按肩宽归一化，左右手都支持。伤害 31，冷却 2 秒。
- 手掌光剑：一只手放在腰间（手腕明显低于肩、贴近身体中线），另一只手向前伸出即可，手肘不必完全伸直；保持 520ms。伤害 14，冷却 2.2 秒。
- 护盾：双腕交叉，双前臂在胸前摆成斜 X 约 120ms；与十字光线、L 形光线判定互斥。护盾最多维持 2 秒，收盾后冷却 4 秒，下一次需要放下双臂后重新交叉。
- 闪避：按首次有效画面的肩部中点记录中心，镜像侧移肩部驱动左右闪避。不需要走动或跳跃；站回中央后可在设置里重新校准。暂停、失焦和影像掉线会释放防御输入。
- 不依赖手指细节，不需要腿部入镜。单人，正面，双臂完整可见。阈值需要儿童实机验证。
- Worker 运行姿态推理，优先 GPU、失败回退 CPU。输入最长边之一按宽度缩放到不超过 640px，约每 65ms 最多提交一帧，单帧背压防堆积。
- 摄像头和视频只在本机处理；关闭影像/离开页面释放摄像头及视频对象 URL。不录制、不上传。

## 无摄像头测试

1. 按键/点击：验证战斗和技能反馈。
2. 英雄视窗导入 MP4：视频循环，设置可调整速度、暂停视频、查看骨骼和诊断；关闭影像可切回按键。
3. `npm test`：覆盖招式、护盾、镜像侧身、持续判定、左右版本、缩放、遮挡与掉帧，以及所有敌方技能、防御结算、打断、冷却、暂停和十四波通关。
4. `npm run test:browser`：另开一个终端启动 `npm run dev -- --dist` 后运行，需要安装 Chrome。可通过 `GAME_URL` 检查公网版本，`CHROME_EXECUTABLE` 指定浏览器。截图统一保存于 D:/tmp/ultraman-browser-check 独立目录。

视频回放和合成关节点不能代替真实摄像头验收。首次家庭测试：先使用成人示范；打开设置的安心练习与诊断；分别测试十字光线、举手挥光轮，以及挥手/整理衣服等负例。记录设备、浏览器、距离、光照与误触发情况；无需上传孩子的视频。

## 技能光效检查

`npm run test:effects` 在浏览器里冻结模拟并逐帧推进，读取真实 WebGL 像素验证蓝白光束、发光光轮、护盾展开和命中爆光；包含手机竖屏、冷却拒绝时不重复生成特效、动画资源清理和光轮命中时序。使用与 test:browser 相同的 GAME_URL / BROWSER_ARTIFACT_DIR 环境变量，截图放在独立任务临时目录。光效是 3D 场景内容，不依赖 HUD 或 DOM 覆盖层。

## 准备界面预加载

打开页面即在独立 Worker 内下载并初始化姿态模型与 WASM，再用空画面推理预热；预热后的慢 GPU 会在此阶段切换 CPU。场景与识别均准备好后才开放进入按钮。预加载不访问摄像头，点击开启影像时才请求权限。关闭摄像头、视频切换及退出战斗只释放影像资源，保留就绪 Worker；页面离开时销毁，浏览器恢复缓存页面后重新准备。识别失败可点“重新准备”，也可选择按键试玩。

`npm run test:preload` 拦截并延迟模型请求验证进入等待、无摄像头访问；检查初始化/预热次数、进入后无模型下载、关闭重开复用、网络失败和恢复重试。`PoseService` 另有并发加载、帧背压与页面资源销毁的单元测试。

怪兽距离参与战斗判定。远处的普通拳不能命中。突进使怪兽留在近身距离，此时会中断远程招式并使用近战攻击。三次近身拳命中后怪兽后退，交替出现击飞。手掌光剑（原「手掌光箭」）的判定按新规则放宽：一只手放在腰间、另一只手向前伸出就算，手肘不必完全伸直；累计保持 520ms（标准 650ms）即发射，中间单帧抖动有 240ms 容错，不会重新计时。举到头顶、垂手站立和横向平举都不会误触发。O 键可试玩。
城市使用 Kenney City Kit Commercial 2.1 CC0 建筑。怪兽使用署名的第三方骨骼模型，鸣谢页及 THIRD_PARTY_NOTICES.md 记录来源。

`npm run test:enemies` 逐段检查三种怪兽的蓄力、攻击、命中和收势，验证雷德王手脚骨骼父子链、手臂长度、出拳位移、远程弹道与伤害时机。截图等待画面完成呈现后保存。
雷德王用单臂直拳、举石投掷和跺脚震波，巴尔坦用钳爪突刺、光弹和扫射，加恩Q 用巨眼光弹、射线与撞击。突进按完整攻击时段推进，击退或击倒会结束敌方光效。

开场约 3.5 秒开始首轮攻击，雷德王和巴尔坦先使用远程招式，再转入突进与近战。

## 音乐、语音与命中反馈

`src/game-audio.js` 用 Web Audio 合成原创海湾战斗主题曲与出拳、命中、受伤、光线、光轮、护盾等音效；不存在运行时模型推理。设置可独立关闭音乐与语音，也可导入本地背景音乐（仅本机播放、不上传）。未打包电视剧配乐。

Qwen3-TTS 官方 Studio 固定 Ryan 音色生成普通话原创场景旁白，压缩为本地 Ogg 文件，随准备界面预载。触发包括开场、受击鼓励、低能量、格挡/闪避、击退、怪兽残血且远处可放光线时的终结提示；胜负采用合成音效。配音有优先级、冷却与音乐压低，暂停、失焦时停止。具体文案与来源见 `public/audio/SOURCE.md`。

近身命中会在对应方向生成冲击环/火花，使怪兽短暂后仰、亮闪并配冲击音。雷德王冲刺用交替腿部步态和前倾躯干，加恩Q 采用完整网格俯冲，巴尔坦保留原生跑步并加入蓝色能量环与速度线。未通过缩放四肢模拟攻击。

`node scripts/combat-feedback-check.mjs` 验证 Z/X 对应独立手臂、左右预备光轮与脱手/命中时序、双血条、音效有效 PCM 与音频设置。真实摄像头深度仍由单目估计，需要在实际站位和孩子动作幅度下调校。
