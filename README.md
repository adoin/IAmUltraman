# 光之小英雄

面向儿童的第一人称 3D 体感游戏。Three.js 渲染巨人视角的城市、迪迦的蒙皮手臂与面前的怪兽；MediaPipe 在本机分析动作。雷德王、巴尔坦星人、加恩Q，五波远近战，三种远程招式、胸前 X 护盾与侧身闪避、星星奖励与合成音效。部署于 https://adoin.github.io/ultraman-play/ 。

## 本地运行

```sh
npm ci
npm test
npm run build
npm run dev
```

打开 http://localhost:4173 。不需要摄像头也能按 J / K 或点击技能卡游玩，按 F 或点击战斗画面普通出拳，按住 L 防御、按住 A / D 侧身闪避。准备区可看动作图解、设置画质难度、开启摄像头和视频预览，确认后再进入。进入后画面只保留城市、怪兽与动作特效，HUD、准星、摄像头预览、文字提示和按钮均在准备区。待机不显示双手，出拳、技能和防御时才显示。Esc / P / 空格或手机双指轻点返回准备区；继续后回到无 HUD 战斗。通关或失败时也返回准备区显示结果。设置包含难度、画质、安心练习与识别诊断。摄像头部署必须 HTTPS；localhost 可开发。使用支持 WebGL 2、Worker、OffscreenCanvas 与 createImageBitmap 的近期 Chrome / Edge / Safari，性能不足可切换流畅画质。

`npm run build` 同步 Three.js 运行时并生成 `dist/`，`npm run dev -- --dist` 预览发布文件。无前端框架或打包器。Three.js、GLB、MediaPipe、WASM 与姿态模型均随站点部署，运行时不请求第三方模型 CDN。字体加载失败自动使用系统字体。

## 3D 模型

`art/models/*.blend` 是 Blender 可编辑源文件，`public/models/kaiju/*.glb` 是网页模型。建模与免费模型来源说明见 [art/README.md](art/README.md)。使用本机 Blender 的后台模式生成，没有修改用户已打开的 Blender 项目。怪兽动画由命名枢轴驱动。迪迦手臂来自 Extrazhang 的连续人物网格。每侧有 18 根手臂和手指动作骨骼，肩根按原模型的双眼和肩骨定位。GLB 纹理和蒙皮着色器在准备界面做离屏预热。

准备界面的“鸣谢”列出模型作者、来源、CC BY-NC 许可及适配说明，并列出 Three.js、MediaPipe、Noto Sans SC 的来源和许可；战斗中该入口与其他 HUD 一同隐藏。本游戏与迪迦模型衍生物为非商业使用。源文件、许可出处、哈希和修改记录见 [art/sources/tiga/SOURCE.md](art/sources/tiga/SOURCE.md)。

`npm run test:tiga` 验证实际 SkinnedMesh、骨骼数、权重归一化、指尖蒙皮位移、纹理、作者元数据、鸣谢及手机动作画幅。

独立[全身动作对照页](https://adoin.github.io/ultraman-play/public/motion-preview/)同步播放同一具迪迦全身骨架的外部视角与双眼视角。试片使用 Quaternius 的 `Punch_Cross` 直拳，保留胸、锁骨、肘腕、五指及腿部动作。点击暂停或拖动时间轴可检查同一帧。这份试片用于验证现成动作的重定向与眼位取景，游戏中的光线仍使用当前游戏动画。

第一人称角色以原模型双眼中点确定肩位。普通动作沿用原始骨长。光线用画面中的肘、腕目标确定横臂长度，袖子网格沿前臂轴向补偿，手掌保持原始尺寸。梅特里姆光线是为迪迦骨骼手调的动作。右肘稍向右打开，右腕处在肘的正上方。左前臂从怪兽一侧横过，左掌朝地。`src/viewmodel-lens.js` 为双臂提供较宽的取景，将光线和光轮的发射位置换算到城市镜头的相同屏幕位置。

`src/action-timing.js` 统一动作、光效和伤害时间：光线在 0.32 秒定姿、0.42 秒开始发射、0.64 秒接触目标；光轮在 0.32 秒脱手、0.74 秒接触目标。光线发射带跟随真实前臂，光轮脱手前跟随手腕方向；命中特效跟随当前怪兽胸部核心。特殊技能占用双臂直到收势结束，期间拒绝其他出拳/技能/防御输入，不消耗被拒绝技能的冷却。

`npm run test:animation` 在 Chrome 中测量肩宽、肩位漂移、两条上臂的入画位置、十字交点处右臂的遮挡以及发射点的屏幕位置。检查覆盖桌面、手机和平板，输出第一人称、正面、侧面和动作阶段截图。发布前查看完整动作，检查肩部轮廓、手型和光效遮挡。截图默认位于 `D:/tmp/ultraman-animation-check`。

## 战斗

普通出拳：每拳 12 点伤害，单次动作间隔至少 0.38 秒，独立于技能冷却、不消耗护盾能量。Pose 根据屈肘收拳→前推伸臂→收回的连续动作判定，不依赖指尖模型；手臂保持伸直不会连发。支持左右手、F 键和点击画面。摄像头前推时的深度由单目姿态估算，需要继续实机验证不同视角与儿童动作。

五波战斗使用雷德王、巴尔坦星人和加恩Q，后续波次增加血量和技能组合。怪兽攻击依次经过蓄力预警、发射和命中判定；蓄力阶段不会扣血。能量弹和冲锋可侧身躲开，横扫需要向提示的安全方向闪避，震波需要护盾；所有攻击都能用有足够能量的护盾格挡。护盾一次最多维持 2 秒，提前松手或到时收盾后冷却 4 秒。持续交叉双臂或按住 L 只触发一次。防御期间消耗能量，收盾后恢复。光线可打断怪兽蓄力。击败怪兽恢复部分生命与护盾，成功防御/闪避额外奖励星星；通关后可重新开始。

## 体感规则

- 光线：肩、肘、腕可见；两条前臂接近，一条偏横、一条偏竖，在胸前保持 420ms（标准 600ms）。释放一次后需要解除姿势再触发。
- 光轮：任意手腕举到肩上并保持，再在 2 秒内向身体外侧挥动。按肩宽归一化，左右手都支持。
- 护盾：双腕交叉，双前臂在胸前摆成斜 X 约 120ms；与十字光线判定互斥。护盾最多维持 2 秒，收盾后冷却 4 秒，下一次需要放下双臂后重新交叉。
- 闪避：按首次有效画面的肩部中点记录中心，镜像侧移肩部驱动左右闪避。不需要走动或跳跃；站回中央后可在设置里重新校准。暂停、失焦和影像掉线会释放防御输入。
- 不依赖手指细节，不需要腿部入镜。单人，正面，双臂完整可见。阈值需要儿童实机验证。
- Worker 运行姿态推理，优先 GPU、失败回退 CPU。输入最长边之一按宽度缩放到不超过 640px，约每 65ms 最多提交一帧，单帧背压防堆积。
- 摄像头和视频只在本机处理；关闭影像/离开页面释放摄像头及视频对象 URL。不录制、不上传。

## 无摄像头测试

1. 按键/点击：验证战斗和技能反馈。
2. 英雄视窗导入 MP4：视频循环，设置可调整速度、暂停视频、查看骨骼和诊断；关闭影像可切回按键。
3. `npm test`：覆盖招式、护盾、镜像侧身、持续判定、左右版本、缩放、遮挡与掉帧，以及所有敌方技能、防御结算、打断、冷却、暂停和五波通关。
4. `npm run test:browser`：另开一个终端启动 `npm run dev -- --dist` 后运行，需要安装 Chrome。可通过 `GAME_URL` 检查公网版本，`CHROME_EXECUTABLE` 指定浏览器。截图统一保存于 D:/tmp/ultraman-browser-check 独立目录。

视频回放和合成关节点不能代替真实摄像头验收。首次家庭测试：先使用成人示范；打开设置的安心练习与诊断；分别测试十字光线、举手挥光轮，以及挥手/整理衣服等负例。记录设备、浏览器、距离、光照与误触发情况；无需上传孩子的视频。

## 发布

源仓库保持私有。GitHub Pages 使用独立公开仓库 `adoin/ultraman-play`，只提交构建输出与第三方许可，从 main 分支根目录发布。更新时运行测试与构建，将 dist 内容（含 .nojekyll）和 THIRD_PARTY_NOTICES.md 同步到发布仓库，再用已认证 Git 提交推送。临时发布检出目录放在 D:/tmp 下的独立任务目录，勿放在仓库集合根目录。源仓库 GitHub Actions 自动执行测试、构建并保存静态站点产物，不需要额外部署密钥。

## 技能光效检查

`npm run test:effects` 在浏览器里冻结模拟并逐帧推进，读取真实 WebGL 像素验证蓝白光束、发光光轮、护盾展开和命中爆光；包含手机竖屏、冷却拒绝时不重复生成特效、动画资源清理和光轮命中时序。使用与 test:browser 相同的 GAME_URL / BROWSER_ARTIFACT_DIR 环境变量，截图放在独立任务临时目录。光效是 3D 场景内容，不依赖 HUD 或 DOM 覆盖层。

## 准备界面预加载

打开页面即在独立 Worker 内下载并初始化姿态模型与 WASM，再用空画面推理预热；预热后的慢 GPU 会在此阶段切换 CPU。场景与识别均准备好后才开放进入按钮。预加载不访问摄像头，点击开启影像时才请求权限。关闭摄像头、视频切换及退出战斗只释放影像资源，保留就绪 Worker；页面离开时销毁，浏览器恢复缓存页面后重新准备。识别失败可点“重新准备”，也可选择按键试玩。

`npm run test:preload` 拦截并延迟模型请求验证进入等待、无摄像头访问；检查初始化/预热次数、进入后无模型下载、关闭重开复用、网络失败和恢复重试。`PoseService` 另有并发加载、帧背压与页面资源销毁的单元测试。

怪兽距离参与战斗判定。远处的普通拳不能命中。突进使怪兽留在近身距离，此时会中断远程招式并使用近战攻击。三次近身拳命中后怪兽后退，交替出现击飞。手掌光箭用单臂向前伸直、另一手收腰并保持 650ms 触发，O 键可试玩。
城市使用 Kenney City Kit Commercial 2.1 CC0 建筑。怪兽使用署名的第三方骨骼模型，鸣谢页及 THIRD_PARTY_NOTICES.md 记录来源。
